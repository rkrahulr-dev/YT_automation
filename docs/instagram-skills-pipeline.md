# Instagram skills in the pipeline

Skills come from https://github.com/Jakeschincariol/instagram-agent-skill (MIT). They write text only and never post. The five Python scripts read and write local files and make no network calls.

| Step | Skill | What it does here |
| --- | --- | --- |
| 1. Plan the week | ig-plan | Sets the Reels, carousels, topics and times, and the daily engagement list |
| 2. Write the hook | ig-reel | Scores hooks from 26 formulas and times the script |
| 3. Build the carousel | ig-carousel | Slide copy and covers at 1080x1350 with a recap slide |
| 4. Write the caption | ig-caption | Checks the feed cut-off, one ask, hashtags |
| 5. Clean the wording | ig-human | Removes AI-sounding wording before review |
| 6. Plan stories | ig-story | 4 to 5 frames a day with one sticker |
| 7. Fix the profile | ig-profile | Scores the profile and rewrites name, bio, pins, highlights |
| 8. After launch | ig-viral, ig-audit | Finds what works in the niche and reviews our posts once there is data |

Per post: ig-plan, then ig-reel or ig-carousel, then ig-caption and ig-human, then Gate 1 (Approved, plus Permission confirmed for clips or Fact checked for carousels), then Gate 2 (publish through Composio after approving that specific post).

Not used: ig-dm, ig-comment, ig-reply and ig-repurpose stay manual or unused for now. ig-profile is used once for the profile.
