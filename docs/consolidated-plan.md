## 3. The weekly cycle

Instagram gets a Reel on Monday, Wednesday and Friday, and a carousel on the other four days. Stories run daily. The Sunday planning routine is skipped, so planning happens on Friday.

| Day | Post | Topic |
| --- | --- | --- |
| Mon | Reel: streamer clip | Streamer highlight |
| Tue | Carousel | GTA 6 settings |
| Wed | Reel: streamer clip | Streamer highlight |
| Thu | Carousel | Cheat codes, only if confirmed |
| Fri | Reel: streamer clip | Streamer highlight |
| Sat | Carousel | Weekly news roundup |
| Sun | Carousel | Beginner tips and map locations |

1. Friday: research the week's topics, draft next week's rows in Notion, run hooks, slides and captions through the skills.
2. Weekend or Monday: the owner reviews rows, picks clips, confirms permissions and sets approved rows to Approved.
3. Post days: publish approved items through Composio only after the owner approves that specific post, then set Status to Posted and record the link.
4. Weekly: pull analytics into the dashboard and report what worked.

## 4. Approval gates and rules

- Gate 1, content: Status set to Approved in the Notion calendar. Streamer clips also need Permission confirmed. Carousels also need Fact checked with a source.
- Gate 2, publish: a post goes out only after the owner approves that specific post. Then it is published through Composio, or WoopSocial as backup, and the link is recorded.

Rules that do not change:

- No streamer footage without that streamer's permission. Every clip is credited by name and platform in the caption.
- No GTA 6 fact without a check against the game or a named source. No GTA 5 cheat codes presented as GTA 6.
- AI videos are labelled fan-made. No copyrighted music. No Rockstar or Take-Two logos, lettering or game art as brand elements.
- Never log in as the owner and never edit the Instagram profile from automation. The owner applies profile changes.
- Three hashtags per post, below the first lines, one ask per post.

## 6. Risks and costs

| Risk | Response |
| --- | --- |
| A streamer refuses or ignores the request | Use another streamer from the list, or switch that day to a carousel |
| Wrong GTA 6 facts in a carousel | Source and Fact checked required before Approved; cheat codes have a fallback topic |
| Take-Two or Rockstar takedown | Original brand, no marks or game art, fan-page notice, name without GTA in it |
| New account reaches no one | Daily stories, 20 minutes of engagement before posting, weekly review |
| Composio upload or free limits fail the test | Fall back to WoopSocial or Clips Kitty's own uploader |
| YouTube keeps new uploads private | Check in the one-clip test before relying on it |

Costs: Notion free plan, Clips Kitty free, instagram-agent skills free, vidIQ free plan once connected. Composio and WoopSocial run on free plans, and Composio's limits are not yet checked. Everygen videos cost credits, checked before each generation.
